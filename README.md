# 财务人工作台 · Finance Workbench

一个给应付会计用的单文件网页工作台，装到手机上可像 App 一样全屏打开。

## 它是什么

纯静态单页应用（一个 `index.html` + 图标 + PWA 配置），**没有后端、没有数据库**。
所有数据（待办、习惯打卡、风控参数、复盘记录）都存在**你自己设备的浏览器 localStorage 里**，
不上传任何服务器。这个仓库只托管「空壳程序」，不含任何个人或公司业务数据。

## 功能模块

| 模块 | 内容 |
|------|------|
| 风控与智库 | 税负率预警 7 维扫描 + 陈奕蔚公开答疑检索（2009–2026） |
| 待办 | 工作 / 生活双清单 |
| 资讯中心 | A 股财报分析、同行对比、宏观与政策 |
| AI 外挂 | 提示词库、财务词典、公式/代码助手、经营报告生成器 |
| 英语学习 | 单词背诵、口语、TED、财务英语 |
| IDEA | 灵机一动、灵感抽牌、每日复盘 |

## 电脑 ⇄ 手机同步

用「🔑 同步码」：数据在本机打包 → gzip → AES-256-GCM 加密（口令经 PBKDF2 十五万轮派生）→
生成一串 `FWS1.` 开头的密文，通过微信等方式自行中转，另一台设备粘贴并用同一口令解密。
明文只存在于设备内存中，中转方看不到内容。

> 口令请自行妥善保存，遗失无法找回。

## 装到安卓桌面

1. 手机 Chrome 打开 Pages 链接
2. 右上角 ⋮ → 「添加到主屏幕」/「安装应用」
3. 桌面出现图标，点开无地址栏，全屏运行

## 技术说明

- PWA：`manifest.webmanifest` + `sw.js`（离线可用）
- 同步加密：WebCrypto（AES-256-GCM / PBKDF2-SHA256）
- 无第三方依赖、无追踪脚本
